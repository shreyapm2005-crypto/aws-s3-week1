About this project

This is a static website built with HTML, CSS and JavaScript for the Amazon S3 static website hosting assignment.

S3 hosting steps

  • Create an S3 bucket and turn off Block Public Access.
  • Upload the website files.
  • Enable static website hosting with index.html as the index document.
  • Add a bucket policy that allows public read access (s3:GetObject).
